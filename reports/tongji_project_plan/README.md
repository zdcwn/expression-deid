## 编译

在项目根目录执行：

```powershell
.\reports\build_reports.ps1 -Target tongji_project_plan
```

脚本优先使用本项目 `.tools/miktex/` 中的 XeLaTeX 和 BibTeX；也可使用系统中的相应命令。源文件使用 BibTeX 后端，兼容编辑器内置预览。输出保存在本目录原有的 `main.pdf`。
