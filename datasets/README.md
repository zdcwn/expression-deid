# 数据集

表情模型用 RAF-DB，座舱画面用 KMU-FED。

数据文件按各自原始许可使用。大规模可选数据集不随主分支分发；换机器时按本地数据路径准备，生成目录按下面的命令重建。

## ppb-emo

本地准备了 Figshare collection 5744171 的 `Facial_expression_data.zip` 中央红外视角 `*-ND.mp4`（PPB-Emo 中性视频）。代码从每段 30 秒视频均匀抽 5 帧，经过 YuNet 关键点对齐到 256×256 灰度；关键点拟合误差超过 12px 的帧只留在审核清单，不进入默认训练。PPB 只按参与者划分训练、验证和测试，不能把相邻视频帧随机拆开。

这是固定驾驶模拟器里的近红外数据，不等于真实道路视频。当前 YuNet 可见光检测器对部分近红外帧可能返回 `no_face`；这种视频需要先换用近红外人脸检测器或提供已裁切的人脸流，不能把失败帧当成模型匿名化失败。

## fer2013-hf

这是 FER2013 像素与 Microsoft FER+ 众包标注的本地配对副本。像素 CSV 来自公开镜像，`fer2013new.csv` 是 FER+ 标注；训练代码按两份文件的原始行号配对，至少 5 票支持同一类别才进入训练。FER+ 主要用于补充不同拍摄条件下的中性脸和高一致性表情，不代表真实座舱域。AffectNet、AFEW、SFEW 等更大的数据集需要按各自页面申请或签署许可，不能绕过访问限制自动抓取。

## kmu-fed

真车近红外，1600×1200。12 个人，1100 张（官方包里有 6 张 `1_` 和 `01_` 重复，已去掉）。

用来做去标识，并检查去标识之后表情还在不在。同一人的不同帧也可以做身份验收。人少，不够单独训练表情模型。没有中性类。

文件名是 `{人编号}_{表情}_{姓名缩写}_{帧号}.jpg`。

| 代号 | 表情 |
| --- | --- |
| AN | 愤怒 |
| DI | 厌恶 |
| FE | 恐惧 |
| HA | 高兴 |
| SA | 悲伤 |
| SU | 惊讶 |

相邻帧几乎一样，不要把每一帧当成一张新样本。启明大学 CVPR 实验室的数据，只许学术使用。

## kmu-fed-aligned

`python -m expression_deid.prepare` 生成，256×256 灰度。原图不改。一张图里多张脸时留面积最大的那张。检不出或关键点不可信的不写图，记在同目录 `manifest.jsonl`。这个目录不进仓库。

读进表情模型时再缩到 100，套 RAF 训练集的均值和方差。不对每张图单独归一，也不做直方图均衡。

## raf-db

对齐后的基本表情，100×100。训练 12271 张，验证 3068 张，一共 15339 张。用来训练和验收表情分类。这些图来自网上，不是座舱摄像头。

官方标签从 1 开始，这里的文件夹从 0 开始，对应关系如下。

| 文件夹 | 表情 |
| --- | --- |
| 0 | 惊讶 |
| 1 | 恐惧 |
| 2 | 厌恶 |
| 3 | 高兴 |
| 4 | 悲伤 |
| 5 | 愤怒 |
| 6 | 中性 |

北京邮电大学的数据，非商业，禁止再分发。中性类里有标错的图，使用时别默认每一张都对。
