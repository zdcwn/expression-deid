# 数据集

表情模型用 RAF-DB，座舱画面用 KMU-FED。两份都只留在本机，不进 Git。许可不允许再转发这些脸。

换电脑时把整个 `datasets` 目录拷过去。GitHub 上只有这份说明。

## kmu-fed

真车近红外，1600×1200。12 个人，1100 张（官方包里有 6 张 `1_` 和 `01_` 重复，已去掉）。

用来做去标识，并检查去标识之后表情还在不在。同一人的不同帧也可以做身份验收。人少，不够单独训练表情模型。没有中性类。

文件名是 `{人编号}_{表情}_{姓名缩写}_{帧号}.jpg`。

| 代号 | 表情 |
| --- | --- |
| AN | 愤怒 |
| DI | 厌恶 |
| FE | 恐惧 |
| HA | 高兴 |
| SA | 悲伤 |
| SU | 惊讶 |

相邻帧几乎一样，不要把每一帧当成一张新样本。启明大学 CVPR 实验室的数据，只许学术使用。

## raf-db

对齐后的基本表情，100×100。训练 12271 张，验证 3068 张，一共 15339 张。用来训练和验收表情分类。这些图来自网上，不是座舱摄像头。

官方标签从 1 开始，这里的文件夹从 0 开始，对应关系如下。

| 文件夹 | 表情 |
| --- | --- |
| 0 | 惊讶 |
| 1 | 恐惧 |
| 2 | 厌恶 |
| 3 | 高兴 |
| 4 | 悲伤 |
| 5 | 愤怒 |
| 6 | 中性 |

北京邮电大学的数据，非商业，禁止再分发。中性类里有标错的图，使用时别默认每一张都对。
